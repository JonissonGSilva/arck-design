# Backend - ArckDesign

Esta pasta está reservada para o desenvolvimento do backend da aplicação ArckDesign.

## Estrutura Futura

O backend será desenvolvido aqui com a seguinte estrutura sugerida:

```
backend/
├── src/
│   ├── controllers/     # Controladores das rotas
│   ├── models/          # Modelos de dados
│   ├── routes/          # Definição de rotas
│   ├── middleware/      # Middlewares
│   ├── services/        # Lógica de negócio
│   ├── utils/           # Utilitários
│   └── config/          # Configurações
├── tests/               # Testes
├── .env                 # Variáveis de ambiente
└── package.json         # Dependências
```

## Tecnologias Sugeridas

- Node.js + Express ou NestJS
- TypeScript
- Prisma ou TypeORM (ORM)
- PostgreSQL ou MongoDB (Banco de dados)
- JWT (Autenticação)
- Multer (Upload de arquivos)
